# 🃏 Memory Card Game

A fun and interactive Memory Card Game built using React. Players flip cards and try to match pairs while testing their memory and concentration skills.

## 🚀 Live Demo

🔗 memory-card-game-nine-black.vercel.app

## ✨ Features

* 🎮 Interactive card-flipping gameplay
* 🧠 Memory-based matching mechanics
* 📱 Responsive design for different screen sizes
* ⚡ Fast and smooth user experience with React
* 🔄 Game reset functionality
* 🏆 Win detection system

## 🛠️ Tech Stack

* React.js
* JavaScript (ES6+)
* CSS3
* HTML5

## 🎯 How to Play

1. Click on a card to reveal its image.
2. Click another card to find its matching pair.
3. If the cards match, they remain open.
4. If they don't match, they flip back.
5. Continue until all pairs are matched.
